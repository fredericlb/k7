# Languages

The builtin plugins' browser half — the desk (`src/turntables/`) and the viewport (`src/video/`) —
is shown in English or French, from a catalogue of its OWN: `messages/en.json` and `fr.json` in
this package, called as `m["area.key"]()`. k7 compiles it with one more paraglide plugin in its
build (`apps/k7/frontend/vite.config.ts`), into `src/paraglide/` here; this package's `i18n` script
does the same for its own typecheck and tests.

## Its own catalogue, because k7 is its only host

A plugin may not import the shell (`plugins.md`), so it cannot call k7's `m`. The other way a
package gets its words — every sentence handed in by the host, as `@studio/ui-library` takes
`LibraryLabels` — would put a hundred desk tooltips into k7's catalogue and thread them through
the SDK's drawer context, for a package nobody else mounts. A catalogue beside the code is what
`@studio/ui-rehearsal` does for the same reason (`packages/ui-rehearsal/docs/i18n.md`).

The rule that a shared package stays English (`apps/k7/frontend/docs/settings.md`) is about a
package drawn by several hosts. These plugins are drawn by k7 alone, so they speak its language.

## k7's language, read and not handed in

The SDK passes no locale, and none is needed: the catalogue is compiled with k7's strategy chain,
`["localStorage", "baseLocale"]`, under the same `PARAGLIDE_LOCALE` key, and a compiled message
reads that key every time it is called. A switch on k7's settings page writes the key, and k7's
`LocaleProvider` remounts the tree the panes sit in, so every message below it is asked again.
The two runtimes cannot disagree as long as the two strategy chains are the same — the vite config
compiles both from one `STRATEGY` constant.

## Rules

- **A sentence stays one message.** Code inside it is `backticked` and `CodeText` draws those
  spans as `<code>`; a literal brace goes in as a parameter, since `{…}` is a hole.
- **A count is two messages**, `.one` and `.other`, picked by `isOne(n)` (`src/i18n.ts`).
- **A table of labels is a table of functions** (`STEM_LABELS` in `ChannelStrip.tsx`), never
  strings read at module scope, which would freeze the first language loaded.
- **`src/messages.test.ts` is the guard**: both catalogues name the same keys and holes.

## What stays English

- **What a server says** — a file-service or library error, a separation's phase.
- **The hardware marks** — `IN`, `OUT`, `KEY`, `SYNC`, `Q`, `BPM`, `÷2`, `×2`: a DJ reads
  them as they are printed on a controller, in either language.
- **The binding diagnostics** — a `mix.yaml` binding that names nothing is reported by
  `@studio/ui-chains`'s resolver, shared with other hosts, in its English.
- **The server half** — the transcription verb and `video/sceneFrom.ts`, which the file-service
  imports and which must not depend on a compiled catalogue.
