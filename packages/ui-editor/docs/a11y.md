# What an editor tells assistive technology

`src/a11y.ts` — two extensions every text pane here mounts: k7's `EditorPane` and `YamlPane`.

## The name is the file

CodeMirror's content element is a `textbox` with no name of its own, and a screen with two panes
open has two of them. `editorLabel` names it after the file it shows, in the host's language
(`project.k7x — editor`), so a person — and a test selecting by role and name — tells them apart.
`YamlPane` takes the label from its host and falls back on the path, since this package holds no
catalogue.

## The vim mode is a status, not a class

Vim's mode shows only as the shape of the cursor, which a screen reader does not see. When vim is
on, a one-line panel under the text carries the mode as `role="status"` named `vim`, with the mode
in vim's own spelling (`NORMAL`, `INSERT`, `VISUAL LINE`…) and in `data-vim-mode`.

It is a panel of ours rather than the vim extension's `status: true` bar: that bar has no role,
is rewritten on every pending keystroke, and takes over the ex prompt's panel. Ours listens to
vim's `vim-mode-change` event and says nothing else, so it speaks only when the mode changes.
