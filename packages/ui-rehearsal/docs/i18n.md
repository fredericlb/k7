# Languages

The rehearsal pages are shown in English or French, and they keep a catalogue of their OWN:
`messages/en.json` and `fr.json` in this package, called as `m["area.key"]()`, the setup in
`src/i18n.ts`. k7 compiles it with a second paraglide plugin in its own build
(`apps/k7/frontend/vite.config.ts`), into `src/paraglide/` here, where the package reads it.

## Its own catalogue, k7's language

A catalogue of its own because these pages hold some four hundred strings that k7's never draws,
and a translator working on them has one file to open, beside the code that uses it. Merging them
into k7's would put two apps' words in one file for no reader's benefit.

The LANGUAGE is k7's: the host calls `followLocale` with its own before anything below renders a
message (`apps/k7/frontend/src/projects/RehearsalHost.tsx`), and both catalogues are compiled with
the same strategy chain, `["localStorage", "baseLocale"]`, under the same key — so a reload agrees
too. The choice, and why it is per browser and English unless chosen, is k7's settings page
(`apps/k7/frontend/docs/settings.md`). A switch redraws in place rather than reloading, so a
running take is not lost to a language change.

A public page is drawn outside that host, so it reads the stored key itself: a visitor who chose a
language on k7 gets it, anyone else English.

## Counts go through the language's own plural rule

A count is two messages, `.one` and `.other`, picked by `isOne(n)`: `Intl.PluralRules` for the
language shown, because French puts 0 in the singular ("0 session") where English does not.

## A package takes its words from its host

`@studio/recorder` carries no catalogue: its components take their words as a `labels` argument,
and this package fills it from its own messages (`src/recorderLabels.ts`) —
`packages/recorder/docs/recorder.md`.

## What stays English

- **What the server says.** An error the server returns (a taken nametag, a failed upload) is
  shown as the server wrote it.
- **The exported files.** The section titles inside an EPUB or PDF export ("Lyrics", "Tablature")
  come from `@studio/rehearsal-shared/epub`, which asks no locale of the browser.
- **What the shared UI package draws.** The dialogs' hidden "Close" is `@frediverse/ui`'s, which
  has no language of its own yet. Its calendar is not in this list: it takes a `locale` and names
  its months and days through Intl.

A date is never printed with the browser's own language: `src/format.ts` binds the recorder's one
date helper to this catalogue's (`packages/recorder/docs/recorder.md`).

Message text is data: a message holding code marks it with backticks, and `CodeText` renders those
spans as `<code>`, so a sentence stays one sentence a translator can reorder.
