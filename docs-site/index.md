# k7 documentation

k7 is a text-first digital audio workstation: a song is a folder of text files, edited in the
browser, the desktop app or on a phone, and played by an audio engine on the machine with the
sound card. Around the editor it carries a media library, a rehearsal recorder, a DJ desk and a
picture compositor.

This site holds two guides, both written from the code as it is today.

| Guide | For | Start here |
|---|---|---|
| [User guide](./user/00-index.md) | Musicians, producers, DJs and VJs using k7 | [What k7 is](./user/01-what-is-k7.md) |
| [Developer guide](./developer/00-index.md) | Contributors to the k7 codebase | [Architecture overview](./developer/02-architecture.md) |

Both guides use the same numbering, so a topic sits at the same number in each: pages 20–29 are
arranging in the user guide and the arrangement code in the developer guide, 40–49 are chains and
modules in both, and so on.
