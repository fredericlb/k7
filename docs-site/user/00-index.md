# k7 user guide

This guide covers everything k7 does, from your first project to playing a gig. Each section
starts with an overview page; the reference pages at the end of a section list every command,
key and field.

New to k7? Read [What k7 is](./01-what-is-k7.md), then [The home page](./03-home-page.md) and
[Project archetypes](./06-archetypes.md) to create your first project.
