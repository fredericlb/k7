# Languages

k7 is shown in English or French. Every string a person reads is a message in
`apps/k7/frontend/messages/en.json` and `fr.json`, called as `m["area.key"]()`; the setup is in
`apps/k7/frontend/src/i18n.ts`.

## The browser decides, unless Settings did

With nothing chosen, the browser's own language wins, then English. The Language card on the
settings screen forces one, and the choice is **per browser** (stored in `localStorage`), not per
account: a phone and a laptop can each keep their own. A switch redraws the app in place rather
than reloading it, so a running take is not lost to a language change.

A public page follows the visitor's browser: it has no settings screen, and it is someone else's.

## Counts go through the language's own plural rule

A count is two messages, `.one` and `.other`, picked by `isOne(n)`: `Intl.PluralRules` for the
language shown, because French puts 0 in the singular ("0 session") where English does not.

## A package takes its words from the app

`@k7/recorder` carries no catalogue. `RecorderView`, `MomentPlayer`, `TagInput` and
`describeMicError` take their words as a `labels` argument with English defaults, and the app fills
it from its own messages (`apps/k7/frontend/src/recorderLabels.ts`). One catalogue per app, not one
per package, is what keeps a translator in a single file.

## What stays English

- **What the server says.** An error the backend returns (a taken nametag, a failed upload) is
  shown as the server wrote it.
- **The exported files.** The section titles inside an EPUB or PDF export ("Lyrics", "Tablature")
  come from the builder the backend's Supernote sync shares, which runs with no browser to ask.
- **What the shared UI package draws.** The calendar's month and weekday names and the dialogs'
  hidden "Close" are `@frediverse/ui`'s, which has no language of its own yet.

Message text is data: a message holding code marks it with backticks, and `CodeText` renders those
spans as `<code>`, so a sentence stays one sentence a translator can reorder.
